# Радио Заброшенная тайга (первый прототип)

Радио встроено в карту и загружается только вместе с MissionTayga.

## Музыкальные файлы

1. Поместите MP3 в sounds/taigaRadio/music/.
2. Для стационарных приёмников подготовьте OGG с тем же содержанием.
   GIANTS createAudioSource официально рассчитан на пространственные аудиофайлы;
   MP3 как вход для него пока не подтверждён.
3. Добавьте записи <track> в sounds/taigaRadio/tracks.xml.
   Укажите существующие файлы и точную продолжительность в миллисекундах.
4. При пустом списке треков модуль не меняет штатное транспортное радио.

Формат:

    <taigaRadio>
        <track title="Название"
               file="sounds/taigaRadio/music/track.mp3"
               speakerFile="sounds/taigaRadio/music/track.ogg"
               durationMs="240000"/>
    </taigaRadio>

speakerFile необязателен для транспортного радио. Если он не задан, трек
не будет проигрываться стационарным радиоприёмником.

Длительность влияет на переход к следующей композиции. Установка
приблизительного значения приведёт к обрыву либо паузе на конце трека.

## Транспортное радио

Станция добавлена как виртуальный канал через методы конкретного
g_soundPlayer: штатные горячие клавиши, стандартный HUD и громкость
AudioGroup.RADIO. Нативный список движка не изменяется.

Это первая версия, не проверенная в работающем клиенте FS25.
Критично проверить воспроизведение MP3 через loadStreamedSample,
переключение на существующие радиостанции, выключение и повторное включение.

## Стационарный радиоприёмник

Специализация карты: taigaRadioReceiver.
Тип placeable карты: taigaRadioPlaceable.

В XML placeable:

    <taigaRadioReceiver
        triggerNode="radioTrigger"
        soundNode="radioSpeaker"
        outerRadius="24"
        innerRadius="3"
        volume="0.65"/>

radioTrigger — I3D Trigger с коллизией игрока.
radioSpeaker — TransformGroup у динамика.

Необходимые элементы I3D и XML радиоприёмников пока не добавлены:
для размещения нужны конкретные модели или координаты существующих объектов.

Стационарные радиоприёмники имеют независимые треки.
Включение и выключение передаются через серверное событие.
Текущая позиция передаётся вновь подключившемуся игроку через onWriteStream.

## Проверка

1. Запустить карту, убедиться в отсутствии ошибок TaigaRadio.
2. В транспортном радио переключиться на виртуальную станцию и обратно.
3. Проверить воспроизведение первой композиции, переключение треков.
4. Добавить placeable с taigaRadioReceiver, проверить триггер и 3D-звук.
5. Проверить двух клиентов, подключение во время звучания и смену трека.

Ни тест с MP3, ни проверка 3D-звука на конкретной I3D-модели ещё не проводились.
